라이브 방송처럼 라이브 채팅이 있는 영상을 열면 YouTube가 저절로 여는 채팅을 닫아 줍니다. 채팅을 직접 열면 그대로 둡니다.

## 하는 일

- YouTube가 라이브 채팅을 스스로 열면, 채팅에 있는 닫기 버튼을 눌러 닫습니다.
- 채팅을 직접 열면, 그 영상에서는 열린 채로 둡니다.
- 페이지를 새로 불러오지 않고 다른 영상으로 넘어갈 때, 백그라운드 탭으로 열었을 때도 동작합니다. 백그라운드 탭은 그 탭으로 넘어간 뒤에 시작합니다.

## 필요한 것

- 데스크톱 사이트(`www.youtube.com`)에서만 동작합니다. 모바일 사이트 `m.youtube.com`은 지원하지 않습니다.

## 언어

버튼 문구가 아니라 요소 id로 채팅과 닫기 버튼을 찾기 때문에, UI 언어와 상관없이 동작합니다.

## 알아 두기

- 스크립트가 직접 보내는 요청은 없고, 어떤 데이터도 모으지 않습니다. YouTube의 버튼을 대신 누를 뿐입니다.
- YouTube가 채팅을 늦게 여는 경우가 있어서, 채팅이 나타난 뒤 15초쯤 지켜봅니다. 그 뒤로는 채팅을 건드리지 않습니다.

## 호환성

- Firefox + Violentmonkey
- Chrome + ScriptCat

## 문제 해결

1. 브라우저 콘솔(F12)을 열고 로그 수준에서 Verbose/디버그를 켭니다.
2. 필터에 `yt-hide-live-chat`을 입력합니다.
3. 정상이면 `checking video` → `closing chat` → `done watching chat` 순서로 찍힙니다.

- `no live chat`: 이 영상에는 라이브 채팅이 없습니다.
- `chat opened by user, leaving it open`: 채팅이 열리기 바로 전에 클릭이나 키 입력이 있어서, 직접 연 것으로 보고 그대로 둔 것입니다.
- 채팅이 열린 채로 있고 `closing chat`이 찍히지 않으면, UI 언어와 브라우저를 피드백으로 알려 주세요.
